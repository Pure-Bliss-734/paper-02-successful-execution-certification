# Reading an episode

The controlled design separates history-to-state reconstruction, state-only action generation and deterministic execution. Strict state fidelity P, immediate support R, action correctness M and realized outcome E can disagree on the same episode. Use `data/state_targets.jsonl` for the semantic target and `data/controlled_tasks.jsonl` for the executor inputs. Each carries a task key. Within each experimental layer, `episode` identifies a saved row; join the layer name and episode with a slash to match a `row_id` in the parsed and scored data. Repeats for the same task stay in the same bootstrap cluster.

`evidence/calls/` preserves the recorded prompts, generation settings, and the exact message text and finish reason wherever a response is available. A null return indicates no stored response body for that attempt. Study attempts with no returned body are explicitly identified. Provider transport envelopes are not inputs to scoring. The 27 capacity episodes in Table 19 exclude a separate preflight. The contract-v1 downstream endpoints and complete-contract M/E use different contracts.

`lineage/` connects the historical plan, admission and ordered response receipts wherever these were recorded. Some core closures were constructed retrospectively. The basis is recorded per layer in `lineage/sources.json`. Historical digests identify the old representation. The public file manifest binds the distributed fields; a projected record cannot be hashed to recover an entire original provider envelope or plan. Selected Qwen state rows retain their original sequence positions without filling in omitted supplemental runs.

The primary controlled and matched analyses, supplied-state interventions, future probe, external repository controls, output-cap sensitivity, natural repair and bridge are distinct denominators. Repository outcome replay uses the archived execution receipts and two deterministic validators. No upstream software execution or hosted inference is required.
